# Data

## Included in this repository

| Directory | Contents |
|-----------|----------|
| `raw/` | Raw GDGT measurement files (small, tracked in git) |
| `cache/TEXAS_posterior_cache/` | Pre-computed forward calibration posteriors (`.nc` files) |
| `cache/TEXAS_invT_posterior_cache/` | Pre-computed inverse temperature posteriors (`.nc` files) |

Cache files can be regenerated by running the SI code notebooks in `notebooks/manuscripts/`.

## Not included — download separately

### `spreadsheets/` — compiled coretop/culture/mesocosm dataset

The main GDGT compilation used for calibration. Available at:
> **Zenodo DOI: TBD** (will be added upon manuscript acceptance)

Place the downloaded files in `data/spreadsheets/` before running `SI_code1_PreProcessing_finalized.ipynb`.

### `external/` — third-party reference datasets

| Dataset | Source |
|---------|--------|
| WOA23 temperature climatology | [NOAA World Ocean Atlas 2023](https://www.ncei.noaa.gov/products/world-ocean-atlas) |
| Zhu et al. 2019 proxy data | [Pangaea](https://doi.org/10.1594/PANGAEA.899208) |
| Tierney et al. 2022 proxy data | see manuscript data availability section |

Download instructions and exact file paths are provided in the data availability section of the manuscript. Place downloaded files in `data/external/` (gitignored due to size, ~310 MB).
